# UI design reference

The approved visual reference is `di-rescue-ui-mockup.png`.

Place the PNG in this directory:

```text
docs/design/di-rescue-ui-mockup.png
```

The image is a design reference only. The plugin UI must be implemented with
JUCE components and vector drawing rather than using the PNG as a background.

The required layout, palette, controls, meters, clipping indicators, and Retina
requirements are documented in [`../CONTEXT_PROTOTYPE.md`](../CONTEXT_PROTOTYPE.md).
